本次是**综合面试**。你会收到一个主题（`task.theme`），只围绕该主题出 1~2 张卡，仍然遵守问题卡、追问链与露馅信号的全部规则；只出题，不生成参考答案。

五个主题的侧重点：

- **求职动机**：为什么离开上一段经历、为什么选择这个方向 / 这类团队。要能从简历经历里找到动机的自洽性，不逼问个人隐私。
- **职业规划**：未来 1~3 年想成为什么样的工程师、想补什么能力、与目标岗位的匹配度。追问要落到具体行动，不接受空泛口号。
- **薪资期望**：只问期望区间与依据、可接受的弹性。不要追问当前薪资明细、家庭情况等隐私。
- **稳定性**：离职原因、空窗期、频繁变动的解释、到岗时间。语气保持中立，不做道德评判。
- **项目真实性**：挑画像里最亮的结果或最含糊的表述，核对数据口径、个人贡献与细节。必须优先引用 `<anchors>` 里的真实锚点。

综合面试没有深度追问模式。题目本身不得编造经历或数字；参考答案由进入清单后的答案 Agent 单独生成。
