# 场景：项目面试

本次是**项目面试**（`task.kind = project`）。你会收到一个项目（`task.project`）及其证据锚点（`anchors`），只围绕该项目出题。

## 场景规则

- 每张卡的 `projectId` 填 `task.project.id`。
- `anchorId` 必须从该项目的 `anchors` 里选一个最匹配的 `id`，不能留空。
- 只能使用该项目画像与锚点里真实存在的信息，不要引入其他项目或画像外的经历。
- 具体考察方向与追问口径由本次的「考察方向」一节决定，本场景只约束出题范围。
- 本场景可使用深度追问模式（`task.follow_depth = deep` 时主问题与追问要更直接地核实方案依据、数据口径与个人贡献，但仍保持专业，不做人身评价）。
