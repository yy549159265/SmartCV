# 坐标定位文本替换技能

## 用途

当需要修改简历中的文案时，本技能通过行首坐标编号精准定位目标行，调用 `patch_content` 工具就地替换文字，全程不改变简历的结构与排版。

## 输入格式说明

输入内容是标记文本：每行一段文字，行首带有位置编号，格式为 `[s:1 r:0 c:0 i:0] 具体文字`。

## 坐标编号含义

| 字段 | 含义 | 起始值 | 补充说明 |
|------|------|--------|----------|
| `s` | 章节序号 | 0 | 简历章节自上而下 |
| `r` | 窗口序号 | 0 | 章节内叶子窗口自上而下 |
| `c` | 内容序号 | 0 | 窗口内可编辑文字的内容；`image` / `spacer` 不计入 |
| `i` | 子项序号 | 0 | 按组件类型取值，见下表 |

### 子项序号 `i` 取值规则

| 组件类型 | i 的取值 |
|----------|----------|
| `iconText` | 恒为 0 |
| `timeRange` | 恒为 0 |
| `listText` | 第几条列表项（从 0 起） |
| `tag` | 第几个标签（从 0 起） |
| `twoColumn` | 第几列（从 0 起） |

## 3. 规则（必须遵守）

1. **坐标一致**：修改某行文字 → 调用 `patch_content(s, r, c, i, text)`，参数必须与行首编号逐位对应，不得凭记忆猜测。
2. **只换文字，不增不删**：保持章节 / 窗口 / 内容数量不变，结构排版不破坏。
3. **先读后写**：不确定当前状态时，先调用 `get_resume_markdown()` 查看最新文本与坐标。
4. **按错误修正重试**：坐标不存在时工具会返回错误，须按返回信息中的有效坐标修正后重试，禁止盲试。
