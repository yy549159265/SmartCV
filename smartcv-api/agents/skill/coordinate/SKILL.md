# 简历坐标：位置编号与正文的对应关系

## 一、标记文本的形态

简历的 JSON 结构会被拍平成一份「一行一段可改文字」的标记文本：

```text
# 基本信息
[s:0 r:0 c:0 i:0] 王先生
[s:0 r:0 c:1 i:0] 138-0000-0000

# 工作经历
[s:1 r:0 c:0 i:0] 2014.1 - 至今
[s:1 r:0 c:1 i:0] 某某公司
```

- `#` 开头的行是章节标题，**只有标题文字，没有坐标**。
- 其余每行形如 `[坐标] 正文`：行首方括号内是这段正文的位置编号，方括号之后就是该编号当前对应的文字。
- 同一份标记文本中，每个坐标只出现一次。

## 二、坐标的四个字段

| 字段 | 名称 | 指向 | 起始值 |
|------|------|------|--------|
| `s` | 章节 | 简历第几个章节 | 0 |
| `r` | 窗口 | 该章节内第几个叶子窗口 | 0 |
| `c` | 内容 | 该窗口内第几个可改文字的内容节点 | 0 |
| `i` | 子项 | 该内容节点内第几个文字单元 | 0 |

四段合起来是一条从章节到具体文字的路径：

```text
简历 → 第 s 个章节 → 第 r 个叶子窗口 → 第 c 个可改内容 → 第 i 个文字单元
```

## 三、`i` 的取值随内容类型变化

| 内容类型 | 一个内容节点对应的文字单元 | `i` 的含义 |
|----------|----------------------------|------------|
| `iconText` | 1 个 | 恒为 0 |
| `timeRange` | 1 个（起止合并成一段） | 恒为 0 |
| `twoColumn` | 每列 1 个 | 第几列（0 起） |
| `listText` | 每个列表项 1 个 | 第几条列表项（0 起） |
| `tag` | 每个标签 1 个 | 第几个标签（0 起） |

也就是说：`c` 定位到「哪个内容节点」，`i` 定位到「该节点里的哪一段文字」。同一个 `c` 下的多个 `i` 是同一内容节点的并列子项，不是不同内容。

## 四、坐标与正文的对应关系

1. **一个坐标恰好对应一段正文。** 坐标是这段正文的唯一地址；反过来，任意一段出现在标记文本里的正文，都由且仅由一个坐标描述。
2. **坐标是结构路径，不是行号。** 行号会随标题、空行、排版变化，坐标只由结构位置决定。同样的文字出现在两处时，行号区分不了，坐标可以。
3. **同级序号一律从 0 开始，按出现顺序递增。** `s` 按章节在数组中的顺序；`r` 按窗口在章节内的遍历顺序；`c` 按内容在窗口内的顺序；`i` 按子项在内容内的顺序。
4. **不计号的节点不占序号。** `image`、`spacer` 没有文字，既不算 `c` 也不出现在标记文本里；容器窗口（内部还有子窗口的行）本身也不算 `r`，只继续展开它的子窗口。因此「界面上第几个元素」与坐标数字不一定相等。
5. **空正文照样占坐标。** 文字为空的行仍然有一行标记，坐标有效，其正文为空字符串。
6. **章节标题没有坐标。** 标题只以 `# 标题` 的形式出现，不属于任何 `[s:.. r:.. c:.. i:..]`。
7. **`timeRange` 的一个坐标对应起止两个字段。** 正文是「起 - 止」拼成的整段文字，起始与结束不拆成两个坐标。
8. **坐标会随结构变化整体重排。** 在某个层级插入或删除节点，会让该层之后的所有同级序号前移或后移；增加 `image` / `spacer` 不改变任何坐标，增加或删除可改文字的内容节点则改变其后的 `c`。
9. **坐标只能指向已有文字。** 章节的增删、顺序、样式、图片、布局都没有坐标，无法用坐标表示。

## 五、示例

结构：

```text
章节 0「基本信息」
  └ 叶子窗口 r:0
      contents: [image, iconText(王先生), spacer, iconText(138-0000-0000)]

章节 1「工作经历」
  └ 容器窗口（不算 r）
      ├ 叶子窗口 r:0: [timeRange(2014.1, 至今), iconText(某某公司)]
      └ 叶子窗口 r:1: [listText(列表项 A, B, C)]
```

拍平后的标记文本：

```text
# 基本信息
[s:0 r:0 c:0 i:0] 王先生
[s:0 r:0 c:1 i:0] 138-0000-0000

# 工作经历
[s:1 r:0 c:0 i:0] 2014.1 - 至今
[s:1 r:0 c:1 i:0] 某某公司
[s:1 r:1 c:0 i:0] 列表项 A
[s:1 r:1 c:0 i:1] 列表项 B
[s:1 r:1 c:0 i:2] 列表项 C
```

对应关系：

- `image` / `spacer` 被跳过，所以手机号是 `c:1` 而不是 `c:3`。
- 容器窗口没有 `r`，它的两个子窗口分别是 `r:0`、`r:1`。
- 三个列表项属于同一个内容节点 `c:0`，靠 `i` 区分。
- `# 基本信息`、`# 工作经历` 没有坐标。

## 六、引用坐标的约定

1. 引用时必须与标记文本行首的四段数字**逐位一致**，顺序固定为 `s`、`r`、`c`、`i`，不得调换或省略。
2. 引用某个坐标时，同时给出该坐标当前的正文原文，便于确认引用指向的是同一段文字。
3. 只引用标记文本中真实存在的坐标；同一层级序号必须在有效范围内。
4. 需要描述没有坐标的对象（章节标题、结构、样式、图片）时，直接说明对象名称，不要硬套坐标。
