# 乱序文本 → 带标记的简历文本（md2md）

## 使用场景

- 输入是一段乱序、零散的文本（笔记、聊天记录、语音转文字、PDF/Word 复制粘贴等）。
- 目标：整理成规范、可读的简历文本，排版采用「章节标题 + 标记行」格式。

## 约束（重点，必须遵守）

1. `#` 章节标题独占一行，标题后换行；不同章节之间空一行；
2. `<end>` 之后必须换行，记录与记录之间不能粘连成一行；
3. 整个输出是「逐行排列」的纯文本：每一行只能是 `#` 标题或一条 `<start>...<end>` 记录；

## 排版规则（必须遵守）

1. 清理噪声：去掉无意义的符号、重复错乱的字符、口水话、换行乱码；把被截断的连续内容就近归并。
2. 只保留简历相关内容：个人信息、教育经历、工作经历、项目经历、职业技能、个人介绍、荣誉奖项等。
3. 不虚构：原文里没有的信息不要编造；缺失的信息一律用「请在这里输入 XX」占位，例如
   「请在这里输入姓名」「请在这里输入手机号」「请在这里输入学校名称」「请在这里输入起止时间」。
4. 排版规则：
   - 每个章节用 `#` 一级标题，如 `# 个人信息`、`# 教育经历`、`# 工作经历`；标题独占一行，前后都要换行；
   - 章节内按行排布，每行一条记录，行格式固定为：
     `<start> 字段1 <windows> 字段2 <windows> 字段3 <end>`
   - `<start>` 表示行开始，`<windows>` 分隔同一行里的多个字段，`<end>` 表示行结束；
   - 字段数量按内容多少决定，一行放不下的并列信息就拆成多行。

## 示例

### 正确示例（注意每行结束都换行，章节之间空一行）
```
# 个人信息
<start> 请在这里输入姓名 <windows> 请在这里输入手机号 <end>
<start> 请在这里输入邮箱 <windows> 请在这里输入所在城市 <end>

# 教育经历
<start> 请在这里输入学校名称 <windows> 请在这里输入专业 <windows> 请在这里输入学历 <end>
```

### 错误示例1（章节漏写#，错误分行）
```
个人信息<start> 请在这里输入姓名 <windows> 请在这里输入手机号 <end><start> 请在这里输入邮箱 <windows> 请在这里输入所在城市 <end>
```
