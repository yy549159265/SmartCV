# 简历优化技能（按坐标就地替换文字）

## 用途
优化 agent 拿到的是「每行一段文字 + 行首位置编号」的标记文本，例如：

```
# 工作经历
[s:1 r:0 c:0 i:0] 负责订单系统开发
[s:1 r:0 c:0 i:1] 优化数据库查询
```

位置编号含义：
- s = 章节序号（0 起）
- r = 窗口序号（0 起，章节内叶子窗口自上而下）
- c = 内容序号（0 起，窗口内可改文字的内容，image/spacer 不计）
- i = 子项序号（0 起；iconText/timeRange 恒为 0，listText=第几条，tag=第几个标签，twoColumn=第几列）

## 规则（必须遵守）
1. 修改某行文字 → 调用 `patch_content(s, r, c, i, text)`，参数与行首编号一致。
2. 只替换文字、不增删内容行：保持章节/窗口/内容数量不变，结构排版不破坏。
3. 不确定当前状态时，先调用 `get_resume_markdown()` 看最新文本与坐标。
4. 坐标不存在时工具会返回错误，按返回信息用正确坐标重试。
